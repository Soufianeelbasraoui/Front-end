# ClickStore - Plateforme E-Commerce Moderne

Application web e-commerce moderne, réactive et performante conçue avec React 19 et Vite.

## 🚀 Fonctionnalités Clés

- **Boutique & Catalogue Complet** : Parcourez les articles par catégories (Mode, Électronique, Maison & Meubles, Sacs & Maroquinerie).
- **Ventes Flash & Offres Spéciales** : Page dédiée aux promotions avec filtres dynamiques par catégorie et badges de réduction.
- **Panier & Gestion des Commandes** : Panier d'achat interactif avec calcul automatique des totaux.
- **Favoris (Wishlist)** : Accès rapide aux articles préférés depuis le header.
- **Recherche Intelligente en Direct** : Recherche instantanée avec aperçu des résultats et prix.
- **Espace Authentification & Profil** : Inscription, Connexion et Tableau de Bord client.
- **Design Soigné & Responsive** : Interface fluide, coins arrondis à 5px, compatible mobile, tablette et desktop.

## 🛠️ Technologies Utilisées

- **Framework** : [React 19](https://react.dev/)
- **Bundler / Dev Server** : [Vite 6](https://vitejs.dev/)
- **Routage** : [React Router DOM v7](https://reactrouter.com/)
- **Icônes** : [React Icons](https://react-icons.github.io/react-icons/)
- **Notifications** : [React Toastify](https://fkhadra.github.io/react-toastify/)
- **Styling** : CSS moderne avec variables personnalisées

## 📦 Installation & Lancement

1. **Cloner le dépôt :**
   ```bash
   git clone https://github.com/Soufianeelbasraoui/Front-end.git
   cd Front-end
   ```

2. **Installer les dépendances :**
   ```bash
   npm install
   ```

3. **Lancer le serveur de développement :**
   ```bash
   npm run dev
   ```
   L'application sera accessible sur `http://localhost:5173`.

4. **Construire pour la production :**
   ```bash
   npm run build
   ```
